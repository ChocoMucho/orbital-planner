# DSP icon asset

`icons.webp` is the Dyson Sphere Program sprite sheet published in the MIT-licensed
[FactorioLab](https://github.com/factoriolab/factoriolab) data set. It is bundled
locally so the Windows application can render item and building icons offline.

Source: `public/data/dsp/icons.webp` from the FactorioLab repository.
